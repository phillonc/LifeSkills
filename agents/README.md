# Personal Growth Agent

The `personal-growth-independence-agent` supports a private six-domain growth plan. This repository contains its public, reusable instructions, not personal check-in data.

- `personal-growth-independence-agent.xml`: DSDM-style agent definition.
- `personal-growth-independence-agent.md`: Operating instructions and review format.
- `../docs/personal-growth-independence-plan.md`: High-level goals and milestones.

**Invocation:** Load these instructions in an agent runtime or an AI assistant and request a daily, weekly, monthly or quarterly review. The repository contains no running scheduler, LHS API connection or deployed automation. Those require a separately configured runtime and authorisation.
